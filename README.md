# VeloMarket 🛒
### Онлайн магазин фиксированных цен

Flutter-приложение 

---

## 📱 Функциональность

- **Главная страница** — баннеры, флэш-распродажа с таймером, категории, товарная сетка
- **Поиск** — поиск по товарам с историей и популярными запросами
- **Карточка товара** — подробная страница с ценой, скидкой, отзывами
- **Корзина** — добавление/удаление товаров, изменение количества, оформление
- **Избранное** — сохранение понравившихся товаров
- **Профиль** — личный кабинет, статистика заказов

---

## 🚀 Установка и запуск

### Требования
- Flutter SDK 3.0.0+
- Dart SDK 3.0.0+
- Android Studio / VS Code
- Android Emulator или физическое устройство

### Шаги

```bash
# 1. Перейдите в папку проекта
cd velomarket

# 2. Установите зависимости
flutter pub get

# 3. Запустите приложение
flutter run

# Собрать APK для Android
flutter build apk --release
```

## 📁 Структура проекта

```
lib/
├── main.dart                    # Точка входа + сплэш-экран
├── models/
│   ├── product.dart             # Модель товара
│   └── cart.dart                # Модель корзины
├── data/
│   ├── products_data.dart       # Товары, категории, баннеры
│   └── app_state.dart           # Глобальное состояние (Provider)
├── screens/
│   ├── main_screen.dart         # Нижняя навигация
│   ├── home_screen.dart         # Главная страница
│   ├── product_detail_screen.dart # Страница товара
│   ├── cart_screen.dart         # Корзина
│   ├── search_screen.dart       # Поиск
│   ├── favorites_screen.dart    # Избранное
│   └── profile_screen.dart      # Профиль
└── widgets/
    ├── product_card.dart        # Карточка товара
    ├── banner_carousel.dart     # Баннер-слайдер
    ├── category_chips.dart      # Чипы категорий
    └── flash_sale_section.dart  # Секция распродажи с таймером
```
