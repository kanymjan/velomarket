# Лабораторные работы по базам данных (C# Windows Forms)

## Выполненные лабораторные работы

### ✅ Лабораторная работа №1 - Windows-приложение
**Папка:** `Lab1_WindowsApp\Lab1`
**Описание:** Создание простого Windows Forms приложения с кнопками, которые меняют цвета при нажатии и выводят приветствие.
**Функционал:**
- Две кнопки (красная и синяя)
- При нажатии кнопки меняются цветами
- Вывод текста "Hello, Бишкек!"

### ✅ Лабораторная работа №2 - Компоненты окна
**Папка:** `Lab2_Components\Lab2`
**Описание:** Работа с компонентами Label, TextBox, GroupBox. Вычисление характеристик цилиндра.
**Функционал:**
- Ввод радиуса и высоты цилиндра
- Автоматический расчет площади основания, объема и площади поверхности
- Обработка событий потери фокуса (Leave)
- Вывод результатов при закрытии формы

### ✅ Лабораторная работа №3 - Обработка ошибок
**Папка:** `Lab3_Exceptions\Lab3`
**Описание:** Обработка исключений при вводе данных с помощью try-catch блоков.
**Функционал:**
- Обработка некорректного ввода данных
- Использование try-catch для предотвращения сбоев
- Установка значений по умолчанию при ошибках

### ✅ Лабораторная работа №4 - Линейные алгоритмы
**Папка:** `Lab4_Linear\Lab4`
**Описание:** Вычисление математических функций по формулам.
**Функционал:**
- Ввод значения X
- Вычисление Y(x) = sqrt(x² + 1) + sin(x)
- Вывод результата с точностью до 4 знаков

### 📁 Лабораторная работа №7 - Одномерные массивы

## Как запустить проекты

### Требования:
- .NET SDK 6.0 или выше
- Visual Studio 2022 или VS Code

### Запуск:
1. Откройте папку нужной лабораторной работы
2. Перейдите в подпапку с проектом (например, `Lab1_WindowsApp\Lab1`)
3. Выполните команду:
   ```
   dotnet run
   ```
   или откройте .csproj файл в Visual Studio

### Компиляция:
```bash
cd Lab1_WindowsApp\Lab1
dotnet build
```

## Структура проектов

Каждый проект содержит:
- `Form1.cs` - основной код формы
- `Form1.Designer.cs` - код дизайнера (автоматически генерируемый)
- `Program.cs` - точка входа приложения
- `Lab*.csproj` - файл проекта

## Примечания

- Все проекты созданы на C# с использованием Windows Forms
- Используется .NET 6.0 (можно обновить до более новой версии)
- Проекты готовы к запуску и компиляции
- Для полной функциональности лабораторных работ №5-12 требуется дополнительная реализация
