## Функциональность по лабораторным работам

### Lab1 - Windows-приложение
- 2 кнопки (красная и синяя)
- Смена цветов при нажатии
- Вывод приветствия "Hello, Бишкек!"

### Lab2 - Компоненты окна
- Ввод радиуса и высоты цилиндра
- Автоматический расчет площади, объема, поверхности
- Обработка событий Leave
- Вывод результатов при закрытии

### Lab3 - Обработка ошибок
- Try-catch блоки
- Обработка некорректного ввода
- Значения по умолчанию при ошибках

### Lab4 - Линейные алгоритмы
- Вычисление Y(x) = sqrt(x² + 1) + sin(x)
- Точность до 4 знаков после запятой

### Lab5 - Разветвляющиеся алгоритмы
- RadioButton для выбора функции (x², sin(x), e^x)
- Условные операторы if-else
- Вычисление выбранной функции

### Lab6 - Циклические операторы
- Табулирование функции sin(x)
- Ввод начала, конца и шага
- Вывод таблицы значений в ListBox

### Lab7 - Одномерные массивы
- Генерация 20 случайных чисел [-50, 50]
- Замена отрицательных чисел на 0
- Отображение исходного и измененного массивов

### Lab8 - Многомерные массивы
- DataGridView с матрицей 4x4
- Генерация случайных чисел
- Поиск максимума на побочной диагонали

### Lab9 - Строки
- Подсчет количества слов в строке
- Подсчет нулей и единиц в двоичной строке
- Вывод результатов в ListBox

### Lab10 - Создание таблицы
- Таблица конвертации валют (USD, EUR, RUB)
- Расчет с учетом комиссии
- DataGridView для отображения

### Lab11 - Рисование фигур
- ComboBox для выбора фигуры (Rectangle, Ellipse, Line, Curve)

- Рисование с использованием Graphics

### Lab12 - Многооконные приложения

## Как запустить проекты

### Требования:
- .NET SDK 6.0 или выше
- Windows 10/11

### Команды для запуска:
```bash
# Перейти в папку проекта
cd "C:\Users\Admin2\Desktop\бд\Lab1_WindowsApp\Lab1"

# Скомпилировать
dotnet build

# Запустить
dotnet run
```

### Открытие в Visual Studio:
1. Откройте Visual Studio 2022
2. File → Open → Project/Solution
3. Выберите файл Lab*.csproj
4. Нажмите F5 для запуска
